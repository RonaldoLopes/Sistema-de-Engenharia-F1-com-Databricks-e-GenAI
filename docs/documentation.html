Objetivo Principal

Construir um Data Lakehouse escalável e governado para análise de dados históricos e em tempo real da F1.

🗂️

Governança centralizada com Unity Catalog. Todas as tabelas residem no catálogo f1_lakehouse.

Fontes de Dados

APIs e datasets utilizados na ingestão

Ergast API (Jolpica)

REST / JSON · Primária

Dados históricos da F1 desde 1950. Cobre pilotos, equipes, corridas e resultados.

OpenF1.org

REST / JSON · Tempo Real

Dados de sessões em tempo real, telemetria básica e posições ao vivo.

FastF1

Biblioteca Python · Telemetria

Telemetria detalhada por volta: velocidade, DRS, ERS, setores e timing.

Kaggle Datasets

CSV · Complementar

Datasets históricos enriquecidos com metadados de circuitos e estatísticas adicionais.

DLT Expectations — Qualidade de Dados

Regras de qualidade aplicadas em cada tabela do pipeline

silver.drivers

  • valid_driver_id — driver_id IS NOT NULL
  • valid_name — full_name IS NOT NULL

silver.results

  • valid_driver_id — driver_id IS NOT NULL
  • valid_points — points >= 0
  • valid_position — final_position IS NULL OR final_position > 0

gold.driver_standings

  • valid_driver_id — driver_id IS NOT NULL
  • valid_season — season IS NOT NULL
  • valid_championship_position — championship_position > 0
  • non_negative_points — total_points >= 0

gold.season_progression

  • valid_driver_id — driver_id IS NOT NULL
  • valid_round — round IS NOT NULL
  • valid_season — season IS NOT NULL

gold.race_summary_facts

  • valid_season — season IS NOT NULL
  • valid_round — round IS NOT NULL
  • has_starters — total_starters > 0
